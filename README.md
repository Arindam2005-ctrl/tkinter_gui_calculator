A desktop calculator application built using Python and Tkinter.
This project supports basic arithmetic operations along with percentage calculation, square root, sign toggle, and decimal handling. It is designed with a clean and user-friendly interface, making it ideal for beginners learning Python GUI development.

✨ Features

Addition, Subtraction, Multiplication, Division

Percentage (%) calculation

Square Root (√) function

Sign toggle (+ / −)

Decimal number support

Clear (AC) button

Simple and intuitive GUI

🛠️ Technologies Used

Python

Tkinter

Math module

📸 Preview

GUI-based calculator window similar to a standard desktop calculator.

🚀 How to Run the Project

Make sure Python is installed on your system

Clone the repository:

git clone https://github.com/your-username/tkinter-gui-calculator.git


Navigate to the project folder:

cd tkinter-gui-calculator


Run the program:

python calculator.py
